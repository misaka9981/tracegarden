# Accept a Current runtime and an RC web framework

Tracegarden uses Node.js 26 and TanStack Start with React even though Node 26 is still Current and TanStack Start is still a Release Candidate on 2026-09-01. The project exists partly to exercise modern TypeScript technology, and the owner accepts the upgrade risk; exact versions will be pinned, compatibility will be proven in CI and containers, and experimental product features remain removable behind feature flags rather than adding more prerelease dependencies to persistence.
