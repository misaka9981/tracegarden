# Accept a Current runtime and an RC web framework (superseded)

The original design decision selected Node.js 26 and TanStack Start with React on 2026-09-01, accepting Node's Current status and TanStack Start's Release Candidate status. The project was partly intended to exercise modern TypeScript technology; exact versions were to be pinned, compatibility proven in CI and containers, and experimental product features kept removable behind feature flags rather than adding more prerelease dependencies to persistence. That proposal is historical and no longer describes the implementation or target; [ADR 0006](0006-choose-hono-and-staged-bun-runtime.md) supersedes it with Hono web transport, server-rendered views, and a staged Bun production-runtime migration.
